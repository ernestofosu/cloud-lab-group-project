About GT Library

A shared shelf for the whole institution

GT Library is a cloud-based e-library built so that students and lecturers can upload, discover and read academic resources without depending on printed copies, USB drives or scattered group-chat links.

Every book, lecture note, research paper, assignment brief and past examination paper lives in one searchable catalogue, reviewed by the library team before it becomes public, and backed by cloud storage so it is never tied to a single machine.

How it works

Built around three roles

Students

Search and filter the catalogue, read PDFs online, download where permitted, bookmark favourites, and rate and review what they've read.

Lecturers

Upload books, lecture notes, research papers and assignments, track how their resources are being used, and edit or retire materials at any time.

Administrators

Approve or reject new uploads, manage users and categories, monitor activity, and keep the catalogue accurate and appropriate.

Built for the cloud

Reliable, scalable infrastructure

GT Library runs on Amazon Web Services: the application server sits on an EC2 instance, the catalogue is stored in a managed Amazon RDS MySQL database, and every uploaded file is stored in Amazon S3 — so the collection keeps growing without running out of disk space.

Amazon EC2
Hosts the JavaScript application
Amazon RDS (MySQL)

Amazon S3
Durable storage for books and cover images
Amazon CloudWatch
